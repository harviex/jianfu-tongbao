# 基层减负线索判定标准（权威版）

> 用途：12345 诉求 → 形式主义为基层增加负担线索 的判读尺度。
> 依据：46/48 条全国通报标准的**本质逻辑**，非拟合任何历史平均值。
> 适用：所有日期、所有地区数据的统一判读。后续新增筛选复用此尺。

## 一、核心判定逻辑（本质，非字面）

**相关** = 诉求反映的基层负担，其**直接动因是"上级为检查/考核/指标/创建/迎检"而向下摊派**，而非正常工作职责或服务供给不足。

即：**负担来自"对上负责的形式要求"，不是"对下服务的业务量"。**

λ 反例辨析：
- 网格员日常巡查、社区常规值班、创城常态化保洁 → 正常工作量，不算（除非有"为应付特定检查考核"的硬性摊派证据）。
- 学校让家长带教具/填档案 → 家校协同边界，非上级对基层的形式主义摊派，不算。
- 推诿扯皮/态度差/办事慢 → 作风效能问题，非"为考核指标增负"，不算（除非明确为迎检弄虚作假）。

## 二、明确纳入（典型相关）

上级发文/考核指标驱动的硬性负担：
- 强制打卡积分、重复填表报数、多头系统填报、迎检台账留痕
- 周末突击活动（为迎检/文明创建发文部署）
- 强制开会陪会、清单外事项下放甩锅、借调干部
- 创建示范达标评比、督查检查考核过频过滥
- 数据造假（指令报数/代填/虚假整改）
- 盲目决策形象工程（运动式作秀、重复开工）

**关键信号词**：为迎检 / 为考核 / 为创建 / 为达标 / 上级要求 / 文明办 / 卫健局 / 城管局等发文部署 / 排名通报。

## 三、明确排除（NOT 相关，判 false）

1. 正常工作安排导致的加班/忙碌（无"应付特定检查考核"硬性摊派证据）
2. 家校责任边界（家长带教具/填档案/志愿服务）
3. 机关效能/服务态度（推诿/态度差/办事慢/流程繁，除非为迎检弄虚作假）
4. 劳动工资社保纠纷、物业邻里消费维权、医疗交通环境投诉、政策咨询
5. 会议占用休息：仅当该会议是"为迎检/考核/创建"的硬性部署且违反减负规定才算；普通校会/业务会不算

## 四、边界裁决原则

- 有"上级发文部署 + 为迎检考核"实证 → **纳入**
- 仅有"基层忙/加班/负担重"但无上级考核驱动证据 → **排除**
- 拿不准时 → **判 false（宁漏勿宽）**，因标准本质是对上形式摊派

## 五、输出约束

- `is_relevant`: true/false
- `subcategory`: 必须从 46 个标准细分类中精确选择一个（原文复制）；不相关填"无"
- `root_cause`: 核心根因（如"为应付上级检查/考核/指标而增加一线无谓负担"）
- `confidence`: 0.0-1.0

## 六、工程约束（ca 机 Ollama 已知坑）

- ca(192.168.123.33) Ollama 版本旧，`/api/generate` 端点已 404，`enable_thinking` 参数对长 prompt 失效。
- 必须用 `/api/chat` + prompt 开头 `<think:6124c78e>\n</think:6124c78e>` 标签强制关 Qwen3 思考，否则 content 为空。
- qwen3.8-9b-clean 在严格长 prompt 下偶发思考标签失效（content 空/非JSON，约 10-30%），需解析失败重试（现 `_llm_batch_classify` 已加重试 2 次）。
- `num_predict: 2048` 足够；prompt 用 `short_standards`（类名）避免超 ca 的 4096 ctx。
